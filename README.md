# Eventday Login — React

Frontend React yang dibuat semirip mungkin dengan desain login pada referensi.

## Jalankan

```bash
npm install
npm run dev
```

Kemudian buka URL Vite yang muncul di terminal.

## Struktur

- `src/App.jsx` — komponen halaman login
- `src/styles.css` — seluruh styling dan posisi layout
- `src/main.jsx` — entry point React
